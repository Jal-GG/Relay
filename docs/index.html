Core Architecture

Relay is a proof-of-concept distributed systems platform designed to run LLMs via Pipeline Parallelism.

Heterogeneous Hardware

Mix and match CPUs and GPUs seamlessly. The system detects CUDA availability and routes layers appropriately across consumer devices.

Dynamic Layer Splitting

Model state dicts are split by layer ranges across machines, ensuring no single node runs out of memory (VRAM/RAM) during inference.

Fault-Tolerant Heartbeats

Workers report live metrics every 5 seconds. If a worker goes offline, tasks fail gracefully and are marked for reallocation automatically.

Backend Agnostic

The coordinator orchestrates tensor serialization (activations) without needing to know if the underlying execution environment is PyTorch CUDA or CPU.

Quick Start

01

Start the Coordinator

The Coordinator tracks cluster state and serves the API and Dashboard.

$ python -m coordinator.main
02

Run Inference!

Submit a prompt. The coordinator routes it through the pipeline.

$ curl -X POST http://localhost:8000/generate \
> -H "Content-Type: application/json" \
> -d '{"prompt":"The capital of France is"}'
03

Attach Worker Nodes

Start your workers on the network and register them with the Coordinator.

Worker A (CPU Node)
$ python -m worker.main http://localhost:8000 \
--worker-id cpu-node-1 \
--model TinyLlama/TinyLlama-1.1B-Chat-v1.0 \
--layers 6:12 --inference-port 9001
Worker B (GPU Node)
$ python -m worker.main http://localhost:8000 \
--worker-id gpu-node-1 \
--model TinyLlama/TinyLlama-1.1B-Chat-v1.0 \
--layers 12:22 --inference-port 9002
